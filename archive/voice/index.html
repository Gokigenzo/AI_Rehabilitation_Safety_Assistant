🎙 Elder Voice Command Assistant

Offline Emergency-Enabled Voice Support for Elderly Care

About the Project

The Elder Voice Command Assistant is an offline, voice-controlled system designed to assist elderly users with daily interactions and emergency situations. The system prioritizes reliability, simplicity, and safety independently of internet connectivity.

Core Features

  • Offline operation: Uses the Vosk speech recognition engine for absolute privacy and reliability.
  • Emergency alert: Repeated voice warnings and popup alerts activated via phrase or button.
  • Medicine reminders: Set relative reminders for medication taking.
  • Elder-friendly Interface: Very simple Tkinter GUI logic limiting complex navigation.
